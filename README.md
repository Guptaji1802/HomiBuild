# 🏗️ HomiBuild - AI Powered Architectural Design Platform

HomiBuild is a visionary project that allows users to auto-generate 3D building models (like houses, bridges, dams, etc.) using only simple inputs like plot size, location, and BHK requirements — no architect or manual design required.

It combines AI, modern UI, and backend automation to provide an end-to-end infrastructure planning solution.

---

## 💡 Key Features

- 🔍 Input land size, location, facing, and BHK count
- 🧠 AI-generated design logic (FastAPI backend)
- 🌐 Interactive frontend (HTML + JS)
- 🖼️ Instant 3D model preview
- 💾 Future-ready for ML model integration (like topography, sea-level analysis)

---

## 🚀 How It Works

1. User enters land details in the form
2. Backend receives data using FastAPI
3. Based on the input, it generates a 3D house model (placeholder image currently)
4. User sees the result instantly on the same page

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI, Uvicorn
- **Tools Used:** VS Code, Git, GitHub
